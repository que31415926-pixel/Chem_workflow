# 项目一　游离藜芦醚的脱氢硼化

**首要判断**是已知钴母体在目标条件下是否真的有缺口。固定游离藜芦醚、HBpin 为唯一外加硼源、无牺牲烯烃、无铬预配位。现阶段项目条件为 50 °C、48 h、HBpin 1.2 当量、按 Co 原子计 4 mol%；它们是待测条件。其他催化剂或 B₂pin₂ 路线的高收率需单列。

1. 查看 `species.json` 和 `xyz/co_me.xyz`。中心吡啶 3,5-Me₂、4-H，两个外侧 N-iPr。CoMe 是预催化剂，`co_h`、`co_bpin` 是候选中间体。每个金属物种先检查配位与最低合理自旋；人工搭建 C–H 活化或 H₂ 释放的路径时明确原子映射。H₂ 逸出的自由能需要实验气相分压/标准态及溶解平衡。
2. 用 `benchmarks.csv` 复核文献参照。Shimozono SI S29–30 给出单重态气相优化/频率、苯连续介质单点以及两种芳烃过渡态的数据。优先复核 meta/para 排序。它是计算方法的对照。Scheme 4A 的 22%、2%、92% 是 23 °C 二硼体系添加剂扰动，不能填入 50 °C 目标格。Das 的 94% 来自另一 B₂pin₂ 路线，铑/HBpin 专利实例也已做出同产物。
3. 用 `simulate co` 比较 C–H 活化慢、含氢中间体释放慢/回捕、离开循环的钴物种积累。模型中的 F、FB、HH、D 为有效物种池。FB 是一个 HBpin 当量处于钴池中的记账状态，HH/D 各携两个可转移氢当量，不能据曲线命名真实配合物。背景支路允许两份 HBpin 形成 B₂pin₂ 和 H₂。模型同时核对芳基、硼、钴和可转移氢守恒。
4. 合作实验先核母体、标品/回收、H₂ 定量及发表阳性，再排同条件的母体、可获得的 Et 已知体系与无钴空白；若已知体系够用就暂缓新配体。产率与总钴 TON 同列，含受体阳性只证明装置和分析可工作。气相与液相均计量，比较必须匹配搅拌、溶剂损失与液气比。
5. 若出现真实缺口且收支可信，根据实际证据选择**一条**干预。降低氢分压能够恢复时，优先评估已知体系的条件改善；有可定位的 C4 加成/失活，再比单一 C4 取代；放氢构型受限有支持后再考虑间隔臂。三个独立日同批比较，达到课题组暂定的 60% 目标（4 mol% Co 时 TON 15）仍应对照最佳已有配体、误差及另一留出芳醚。

**模型的使用边界。** `Hgas` 的单位是气相 H₂ 摩尔数除以液相体积（M 等效），与气相压力之间要用实际顶空体积/温度换算。`headspace` 用回溶系数的变化代表改变液气容量，`arene_D` 用假定的正向速率系数模拟同位素干预；都需要实测参数。当前网络不含预催化剂活化、区位异构体分布及明确的微观热力学约束。扩展到新配体、变温或不同气液装置时应加入经实验约束的正逆速率、平衡及失活物种。预测的 D 池只有在能被实际鉴定/定量后才可当作拟合观测。
