# Calibrate and validate a stability threshold

A study owner freezes the scalar score definition, its method, units, sign, source records and group-wise split before inspecting computed rankings. Supply the same registration and its SHA-256 to two analysis tasks with stage `mechanism`. Digests for JSON records use UTF-8, sorted keys, compact separators, literal Unicode and finite JSON numbers. The stored review date and the underlying original documents belong in the study’s scientific review record. Content hashes establish byte identity, not chronology.

1. Set registration fields `score_id`, `score_protocol_sha256`, `unit`, `higher_scores` (`stable` or `unstable`), `threshold_rule` (`midpoint_of_strict_class_gap`) and `limitations`. In `anchors`, map each registered anchor ID to `split` (`train` or `heldout`), `group_id`, `condition_id`, `source_locator`, `source_sha256` and `observation_sha256`. Equivalent salts or repeated observations must use the same group across publications. A group cannot enter both splits. The two counts differ by at most one.
2. Run `fit_anchor_threshold` with `registration`, `registration_sha256` and `training`. Each training ID maps to an `observation` and a `score`. The observation supplies `id`, `label`, `group_id`, `condition_id`, `source_locator` and `source_sha256`; its hash must match the precommitment. The score supplies `score_id`, `score_protocol_sha256`, `unit`, `group_id`, `condition_id`, `artifact_sha256`, `lower` and `upper`. Use evidence from the preregistered calculation and preparation conditions. A point estimate has equal lower and upper endpoints.
3. Run `score_anchor_threshold` using `registration`, `registration_sha256`, `heldout` (same record format) and `calibration` bound to the complete training report from the preceding task. No fitting occurs during scoring. Ranking requires all held-out intervals to fall strictly on the correct side of the frozen threshold. The report retains source overlap, represented classes and the supplied limitations.

An overlap of score uncertainty with the boundary is indeterminate. Missing observations or absent training classes are missing evidence. An observed wrong-side holdout blocks ranking while preserving the numerical results upstream. A successful check on a few qualitative anchors from differing preparation conditions does not establish universal salt stability.
