# 项目二　二级苄基端与三级烷基端的偶联

拟检验的目标是 Ph–CH(CH₃)–C(CH₃)₃，特戊酸供给叔丁基，1-苯乙胺衍生盐供给二级苄基。Zhao 的 F10 在**醇程序 B** 中报告 0% UPLC，对氯芳环和 N-Boc-4-甲基哌啶醇与本目标不同；其单例未给定量下限。酸程序 A 的目标结果尚待实测。原盐无法在入瓶时定量，铁端就可能无法评价。

1. 查看 `species.json`。含一级/二级原环、2-iPr 改环盐、对应还原态、自由基、Fe(OEP)Cl、Fe(II)–OEP、一级/二级苄基铁及反应复合物的初猜。盐先做有机构象搜索，再计算孤立阳离子接受电子及 C–N 裂解；实际定量需另考察对离子、离子对、溶剂和光催化剂氧化还原参比。改环一级与二级应成对。多个铁自旋态、轴配体和自旋耦合应分别审核。
2. 用文献约束单个步骤。`benchmarks.csv` 中铁–甲基/乙基/新戊基在苯中的值是热均裂**活化焓**。不能拿基态解离自由能或 SH2 势垒去打分。吡啶鎓盐的电位需在相同参比/溶剂下比较，且电位不直接给出自由基供应速率。F10 已启发本项目，只可作已知邻例。保留一整组未参与选模型的同路线数据作为验证。
3. `simulate fe` 对比盐先损失、铁–碳键寿命短及后续 SH2 成键慢。模型含铁截留/释放、独立光解、游离交叉偶联、两端二聚及副反应，分别核对苄基、叔烷基与总铁守恒。`no_Fe` 示例把两端光生速率放大 1.25 倍，演示铁卟啉吸蓝光产生的混杂；倍率应由同装置光度/光通量及动力学确定。`bypass` 用同一片段的替代供给来比较前体问题，源强需单独定标。
4. `handoff fe` 的第一批只查盐在真实溶剂/碱暗置后的有效量、产物标品回收和酸程序 A 已知阳性。第二批以同环、同日的一级＋特戊酸为参照，测目标二级样及无铁背景。目标已达到实用水平则先做真实留出片段，暂缓改铁配体。低效且可重复时再比较独立自由基来源。供给可比而仍低效，才投入铁捕获、铁烷基释放及成键研究。取样要同时记录液相苄基副产物、气相异丁烯/异丁烷、两端二聚及独立批次。
5. 若要把结论从特戊酸推广，用可生成同一 N-Boc 哌啶三级片段的醇/酸做桥接，苄基端固定对氯和同吡啶环，分别做一级/二级。醇/酸走各自阳性及文献程序，光催化剂、活化和溶剂也可能随路线改变。再用另一芳环及另一三级酸做留出。这个矩阵在单一目标已有判别价值后才扩展。

**该模型只处理酸路线和一种苄基类别。** `Fe` 是可捕获自由基的有效起始池，未描述氯代预催化剂的活化。缓慢 SH2 与自由终止可能给出相同终点。使用模型讨论一级/二级差异时，需为每类准备自己的通量及参数并在同批条件下比较。单个无铁产率、检出 CO₂ 或单个自由基捕获峰不能指定成键经过哪一路。
